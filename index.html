Keep Structogram close

Safari on Mac (macOS Sonoma or later): choose File → Add to Dock. This opens the editor in its own window.

Chrome / Edge: use the install icon in the address bar, or the browser menu → Install app.

iPhone / iPad: Safari → Share → Add to Home Screen.

Wait for “Ready offline” before disconnecting. Your work stays in this browser profile. Use Save source to keep a backup: clearing site data can remove your document and offline access. After adding the app, open it once online to prepare its offline copy; use Open file to transfer a saved .ads document if needed.

No Terminal commands or Mac security exceptions are needed.
A QUICK REFERENCE

Write it like your lectures.

Blocks: drag an Algorithm block, put Statement, If, While, or For blocks inside, and edit their text fields. Case blocks belong inside a Selection. Empty bodies become SKIP. Use Undo/Redo to revert a block change.

Text: start with a routine signature and indent its statements with two spaces. Switch between modes to edit the same algorithm; incorrect text must be fixed before switching to Blocks. The editor draws pseudocode but never executes it.

search(t : Node*; k : T) : Node*
  while t ≠ ∅ ∧ t→key ≠ k
    if k < t→key
      t := t→left
    else
      t := t→right
  return t

Constructs

if condition, else if condition, else
while condition
for i := 0 to n − 1
for u ∈ G.V
select with indented case condition branches and optional otherwise.

An omitted else becomes SKIP. A routine or control block needs a body. You can put several routines in one document.

Course notation

:= assignment · = equality
∅ null pointer · → pointer field
∧ ∨ ¬ logical operators
∀ ∈ iteration over a collection

In the diagram, -> != <= >= && || become → ≠ ≤ ≥ ∧ ∨. Source text stays as typed. Use // for a comment row.
